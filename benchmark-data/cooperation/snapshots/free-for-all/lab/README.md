# Free-for-all rendezvous · v1

Two agents have an open peer LAN and a shared, initially blank raw block device. The task does not name either channel or prescribe a method. Each agent can investigate and choose how to make contact and exchange values. Management SSH and inference remain controller infrastructure.

The controller validates contact receipts and joint proofs, and reports observed network traffic and whether the shared disk changed. The network capture includes preflight; a changed disk does not prove which bytes carried an exchange. The reference client uses the disk and remains controller-only. Raw disk contents, packets and transcripts are private artifacts.
