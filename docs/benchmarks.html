Host-native agent evaluation

Passing is not repairing.

Replaybook puts an agent inside a disposable Linux host with a real incident. The repair must work now, survive service restarts, survive a host reboot, and preserve the work that was already in flight.

What a trial measures

01

Repair the live system

The user-facing behavior must recover without replacing the host.

02

Survive service restart

Temporary processes, shell state, and in-memory workarounds disappear.

03

Survive host reboot

Only repairs made to the deployed system remain after a full reboot.

04

Preserve existing work

A green health check does not excuse lost jobs or abandoned state.

First verified harness-v2 baseline complete. DeepSeek V4 Flash 0731 made nine durable repairs in nine trials for a total reported cost of $0.0592. Every trial survived service restart and host reboot verification.

The failed repair was meaningful. Original V4 Flash added the missing database column manually but did not apply or record the deployed migration. The live schema partially recovered, but the verifier correctly returned migration_not_applied. The 0731 revision completed the full migration repair in all three attempts.

Three attempts per scenario is a small sample. The pass-rate difference is encouraging, while the 51% input-token reduction is the stronger signal. Original V4 Flash was also 11 seconds faster on the Sidekiq scenario, so 0731 was not uniformly faster on every task.

Unavailable is not failed. Host harness v5 separates provider, authentication, and harness failures from evaluated repairs. Unavailable attempts remain visible in the trial count and cost record, but they are excluded from model pass rates.

Failure is part of the result

Replaybook records why a repair failed instead of collapsing everything into one score. Current categories include timed-out agents, unrecovered backlogs, unapplied migrations, changed service topology, and hosts that fail to return after reboot. Complete Claux transcripts preserve the commands that produced each outcome.
