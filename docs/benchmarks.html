DeepSeek was cheapest at about 0.82 cents per repair. HY3 had the fastest median and cost about 1.6 times as much per repair. GLM cost about four times as much as DeepSeek, but was fastest on the Nginx, Redis, and poison job incidents. With every model at 100 percent, these are cost and latency profiles, not reliability rankings.

What counts as current

Current results use host harness v5 and the scenario versions shown above. Harness v5 keeps the oracle and verifier outside the model VM and separates unavailable provider or harness attempts from evaluated model failures. Results from older harnesses remain available under History, but are not mixed into this comparison.

Run the matrix

python integrations/host/run_host_matrix.py \
  --scenario 001-nginx-502-host \
  --scenario 013-sidekiq-wrong-redis \
  --scenario 014-missing-rails-migration \
  --scenario 015-sidekiq-poison-pill \
  --scenario 016-rails-pool-exhaustion \
  --models \
    deepseek/deepseek-v4-pro \
    tencent/hy3-preview \
    z-ai/glm-5.2 \
  --attempts 1 \
  --concurrency 2
